【動画制作指示書：チャンネル1・企画A「渓流×小鳥の3時間 睡眠・作業用」】

■ 完成物
- 尺: 3時間00分00秒（10800秒）
- 動画: 3840×2160（4K）/ 30fps / H.264 / ビットレート35〜45Mbps
- 音声: 48kHz / 24bit / ステレオ / AAC 384kbps以上で書き出し

■ 音声仕様（最重要）
1. レイヤー構成（3層ミックス）
   - L1 主役: 湧き水系の澄んだ渓流のせせらぎ（中〜近距離、粒の細かい水音。滝のような轟音はNG）。これを基準レベルとする
   - L2 小鳥のさえずり: シジュウカラ・メジロ・ウグイス系の穏やかな鳴き声。L1より-8〜-10dB小さく。20〜40秒間隔でランダムに出現させ、左右にゆるくパンを振って空間を作る
   - L3（任意）微風の葉ずれ: L1より-14dB以下でごく薄く敷く
2. 音圧・処理
   - 統合ラウドネス: -14 LUFS前後 / トゥルーピーク: -1.5dBTP以下
   - ハイパスフィルタ 40Hz（低域ノイズカット）
   - 2〜4kHzの耳に刺さる帯域を-2dB程度緩める（長時間リスニング対策）
   - 鳥の警戒音・カラス・飛行機・人声・車の音は必ず除去
3. ループ構造
   - 15分のマスターループを作成し12回連結
   - 連結部は4秒のイコールパワー・クロスフェード
   - 書き出し後、継ぎ目を3箇所以上スペクトログラムで確認し、ノイズ・音量段差がないこと
4. 冒頭5秒フェードイン / 最後10秒フェードアウト

■ 映像仕様
- 新緑の渓流の実写1カット固定（三脚撮影、水面と木漏れ日が動く程度の変化）
- 睡眠視聴を考慮し全体の明度を約10%落とす（白飛びした水しぶきを抑える）
- 画面内にテキスト・ロゴ・透かしを入れない
