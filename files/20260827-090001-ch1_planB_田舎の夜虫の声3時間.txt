【動画制作指示書：チャンネル1・企画B「夏の終わりの田舎の夜・虫の声3時間」】

■ 完成物
- 尺: 3時間00分00秒（10800秒）
- 動画: 3840×2160（4K）/ 30fps / H.264 / ビットレート35〜45Mbps
- 音声: 48kHz / 24bit / ステレオ / AAC 384kbps以上で書き出し

■ 音声仕様（最重要）
1. レイヤー構成（3層ミックス）
   - L1 主役: スズムシ・コオロギ中心の虫の声（8月末〜秋の鳴き声）。これを基準レベルとする。冒頭30分のみヒグラシを薄く重ねて「夏の終わり」の情緒を出す
   - L2 遠くの川のせせらぎ: L1より-10dB小さく、背景として一定に流す
   - L3（任意）遠くの蛙: ごくまれに(10分に1回程度)。犬の吠え声・車・人声は必ず除去
2. 音圧・処理
   - 統合ラウドネス: -14 LUFS前後 / トゥルーピーク: -1.5dBTP以下
   - ハイパスフィルタ 40Hz
   - 3kHz以上を-3dBして、夜のこもった空気感を出す
3. ループ構造
   - 15分のマスターループを作成し12回連結
   - 連結部は4秒のイコールパワー・クロスフェード
   - 書き出し後、継ぎ目を3箇所以上スペクトログラムで確認し、ノイズ・音量段差がないこと
4. 冒頭5秒フェードイン / 最後10秒フェードアウト

■ 映像仕様
- 夜の田園または月明かりの里山の固定カットか静止画
- 全体を暗いネイビートーンに統一。画面内にテキスト・ロゴ・透かしを入れない
