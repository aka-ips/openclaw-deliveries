# YouTube自然系 新作企画プロンプト（詳細版）
📅 2026/08/27（ケンのトレンド分析に基づく）

## トレンド分析からの主要インサイト

1. **「川のせせらぎ × 鳥のさえずり」が最強の組み合わせ** — 自然・川・風・森の4カテゴリに同一動画がランクイン（kazephoto、癒しの水の音ch）。
2. **タイトルの用途キーワード詰め込みが有効** — 【勉強・作業・睡眠・ASMR・自律神経・赤ちゃん寝かしつけ】の複合訴求が上位常連。
3. **4K新緑映像 + 癒しBGMの二本柱** — 癒しの映像館が2本ランクイン。「疲れた心身の回復」「途中広告なし」の明記が信頼要素。
4. **睡眠特化の夜バリエーション** — 「田舎の夜・虫の声・蛙」など夜の環境音が独自ポジション。
5. **超長尺（24/7・3時間以上）が滞在時間を稼ぐ** — Bamboo Water Fountain 24/7 が2カテゴリ入り。

### 制作プロンプト（そのまま制作エージェントに渡す）

```
- 音声: 48kHz / 24bit / ステレオ / AAC 384kbps以上で書き出し

■ 音声仕様（最重要）
1. レイヤー構成（3層ミックス）
   - L1 主役: 湧き水系の澄んだ渓流のせせらぎ（中〜近距離、粒の細かい水音。
     滝のような轟音はNG）… 基準レベル
   - L2 小鳥のさえずり: シジュウカラ・メジロ・ウグイス系の穏やかな鳴き声。
     L1より-8〜-10dB小さく。20〜40秒間隔でランダムに出現させ、
     左右にゆるくパンを振って空間を作る
   - L3 (任意) 微風の葉ずれ: L1より-14dB以下でごく薄く敷く
2. 音圧・処理
   - 統合ラウドネス: -14 LUFS前後 / トゥルーピーク: -1.5dBTP以下
   - ハイパスフィルタ 40Hz（低域ノイズカット）
   - 2〜4kHzの耳に刺さる帯域を-2dB程度緩める（長時間リスニング対策)
   - 鳥の警戒音・カラス・飛行機・人声・車の音は必ず除去
3. ループ構造
   - 15分のマスターループを作成し12回連結
   - 連結部は4秒のイコールパワー・クロスフェード
   - 書き出し後、継ぎ目3箇所以上をスペクトログラムで目視確認し
     「ブツッ」というノイズ・音量段差がないこと
4. 冒頭5秒フェードイン / 最後10秒フェードアウト

■ 映像仕様
- 新緑の渓流の実写1カット固定（三脚撮影、水面と木漏れ日が動く程度の変化）
- 睡眠視聴を考慮し全体の明度を約10%落とす（白飛びした水しぶきを抑える)
- 画面内にテキスト・ロゴ・透かしを入れない
```

# チャンネル2（4K映像型・風景ch）

## 企画A（本命）: 4K渓流シリーズ VOL.2

### 制作プロンプト（そのまま制作エージェントに渡す）

```
【動画制作指示書：チャンネル2・企画A】

■ 完成物
- 尺: 90分 / 3840×2160(4K) / 30fps / ビットレート45Mbps以上
- 音声: 48kHz / 現地環境音＋BGMの2mix

■ カット割り（12カット×約7〜8分、この順で構成）
  1. 渓流全景（引き）: 木々の間を流れる川の全体像。導入
  2. 岩を越える流れ（中景）: 白い水流のディテール
  3. 苔むした岩（寄り）: 水滴が苔に落ちる様子
  4. 木漏れ日（見上げ）: 新緑の葉越しの太陽、レンズは絞って光条を出す
  5. 水面のきらめき（寄り）: 反射光の揺らぎ
  6. 小さな滝（中景）: 白糸のような落水
  7. 森の小道（引き）: 奥行きのある構図で「散歩している感覚」
  8. 葉の上の水滴（マクロ）
  9. 流れに乗る落ち葉（中景）: 晩夏〜初秋の季節感を出す1枚
  10. 渓流と橋/倒木（引き）: 風景に「物語」を作る人工物or自然物
  11. 夕方の柔らかい光の渓流（中景）: 終盤の時間経過を演出
  12. 渓流全景・夕景（引き）: 1カット目と同アングルで一日の終わりを示し締める

■ 撮影・編集規定
- 全カット三脚固定。パン・ズーム禁止（酔い防止）。手ブレ映像は不採用
- カット切替: 1.5秒のディゾルブ。「引き→寄り→引き」のリズムを守る
- カラー: 緑の彩度+10%、コントラスト-5%、ハイライト-10%（目に優しい柔らかさ）

- 統合ラウドネス -16 LUFS / トゥルーピーク -1.5dBTP
```

# 共通の運用ポイント

- 公開直後24時間はコメントに全返信し初速エンゲージメントを確保
- 両チャンネルで説明欄相互リンク＋終了画面で相互誘導
- サムネイルはA/B候補を2枚作り、インプレッションCTR 4%未満なら差し替え
- 3週間後にアナリティクス確認: 平均視聴維持率40%以上の企画の派生
  （10時間版／秋・紅葉版）を次回作にする
