# YouTube自然系 新作企画プロンプト
📅 2026/08/27（ケンのトレンド分析に基づく）

## トレンド分析からの主要インサイト

1. **「川のせせらぎ × 鳥のさえずり」が最強の組み合わせ** — 自然・川・風・森の4カテゴリに同一動画がランクイン（kazephoto、癒しの水の音ch）。
2. **タイトルの用途キーワード詰め込みが有効** — 【勉強・作業・睡眠・ASMR・自律神経・赤ちゃん寝かしつけ】の複合訴求が上位常連。
3. **4K新緑映像 + 癒しBGMの二本柱** — 癒しの映像館が2本ランクイン。「疲れた心身の回復」「途中広告なし」の明記が信頼要素。
4. **睡眠特化の夜バリエーション** — 「田舎の夜・虫の声・蛙」など夜の環境音が独自ポジションを確立。
5. **超長尺（24/7・3時間以上）が滞在時間を稼ぐ** — Bamboo Water Fountain 24/7 が2カテゴリ入り。

## チャンネル1（音メイン型・環境音ch）新作企画

### 企画A（本命）: 渓流×小鳥の長尺睡眠・作業用
- **タイトル案**: 心が整う渓流のせせらぎと小鳥のさえずり 3時間【勉強,作業,集中,睡眠,瞑想,リラックス,赤ちゃん寝かしつけ,自律神経を整える,ASMR,高音質,途中広告なし】
- **尺**: 3時間（将来的に10時間版を派生）
- **音**: 湧き水系の澄んだ水音を主役、小鳥のさえずりを20〜30%の音量で重ねる。ループの継ぎ目が分からないクロスフェード必須。
- **サムネ**: 新緑＋渓流の実写、文字は「脳がとろける」系の感情ワード1つのみ。

### 企画B(差別化): 夜の田舎・虫の声バージョン
- **タイトル案**: 【睡眠用】夏の終わりの田舎の夜 虫の声と遠くの川のせせらぎ 3時間【安眠,ASMR,自然音】
- **狙い**: 夜間検索帯（22時〜2時）の睡眠需要。季節感（8月末→秋の虫）で鮮度を出す。

### 制作プロンプト（そのまま制作エージェントに渡せる形）
```
以下の仕様で環境音動画を制作してください。
- テーマ: 渓流のせせらぎ+小鳥のさえずり（昼) / 田舎の夜の虫の声（夜版）
- 尺: 3時間、ループ継ぎ目なし、-14 LUFS前後で音圧統一、高音質(48kHz)
- 映像: 固定カメラの実写風景1カットまたは緩やかなスライドショー、4K
- タイトル: 感情フック+用途キーワード【】詰め込み型（上記タイトル案を使用）
- 説明欄: 効能(睡眠/集中/自律神経)、タイムスタンプ、「途中広告なし」明記
- タグ: 自然音, せせらぎ, 鳥のさえずり, 睡眠用BGM, 勉強用BGM, ASMR, nature sounds
```

## チャンネル2（4K映像型・風景ch）新作企画

### 企画A（本命）: 4K新緑渓流シリーズ第2弾
- **タイトル案**: 【癒し・4K風景映像】晩夏の渓流と森の光 - VOL.2（鳥のさえずり・川のせせらぎ）疲れた心身の回復に。目覚めの朝や眠れない夜にもどうぞ（途中広告は入れていません）
- **尺**: 1〜2時間
- **映像**: 4K実写。渓流・苔・木漏れ日を10〜15カット、各カット30〜60秒のゆったりした切り替え。CMロケ地系の「名前のある場所」だと検索流入が増える。
- **音**: 現地環境音+控えめな癒しBGM（ハープ/ピアノ系、トレンドの「自律神経に優しいハープ」を意識）。

### 企画B（差別化）: 朝活・目覚め特化版
- **タイトル案**: 【朝の癒し・4K】霧の森の夜明けと鳥のさえずり - 爽やかな1日の始まりに（リラックス・瞑想・ヨガ・朝食BGM）
- **狙い**: 上位動画が「睡眠」に集中する中、朝6〜9時の視聴帯を先取り。

### 制作プロンプト（そのまま制作エージェントに渡せる形）
```
以下の仕様で4K風景映像を制作してください。
- テーマ: 晩夏〜初秋の渓流と森（VOL.2）/ 朝霧の森の夜明け（朝版）
- 尺: 1〜2時間、4K30fps、カット切替はゆっくりしたディゾルブ
- 音: 現地環境音を主体に、ハープまたはピアノの癒しBGMを小さく重ねる
- タイトル: 【癒し・4K風景映像】プレフィックス+効能文+「途中広告は入れていません」
- 説明欄: 撮影地情報、効能、チャプター、関連再生リストへの導線
- タグ: 4K, 癒し, 風景映像, 新緑, 渓流, 鳥のさえずり, relaxing nature
```
