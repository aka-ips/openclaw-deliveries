# HQツール 改修指示書 v1.1（2026-08-24）

出先レビュー（Claude Code リモートセッション）で確認された不備5点への対応指示。
対象: `~/hq/` 一式（charter.md / tools/A.md / spec/A-tool-implementation-spec-v1.0.md / bin/hq / GUIDE.md）。

**運用上の位置づけ:** F2・F3・F5 はルール変更を含むため、ボスの承認語が必要。

> **承認記録:** 2026-08-24、ボスより本チャット（Claude Code リモートセッション）にて
> 承認語「**①YES**」を受領。ハンドブック v1.2 の定め（承認語はTelegram・チャットの
> どちらでも有効）に基づき、**F2・F3・F5 は承認済み**。追加の承認カード起票は不要。
> F1・F4 は既存ルールの整合・保全であり、もとより承認不要。

つまり **F1〜F5 全件、即時適用可**。

## F1. 文書間の矛盾の解消（優先: 高 / 承認不要）

- 設計図 v1.0: 催促は +1h・+3h の最大3回 ／ ハンドブック v1.2: 催促は1回だけ
- 設計図 v1.0: 承認は3つ ／ ハンドブック v1.2: 承認は4種類（④担当変更GO）

**指示:** `~/hq/charter.md`（正本）の現行値を確認し、負けている側の文書を正本に合わせて
更新する。設計図アーティファクト（Blueprint v1.0）にも改訂を反映する。
正本と配布文書の版番号を一致させ、以後は正本を変えたら同一コミットで配布文書も直すこと。

## F2. 静穏時間とタイマーの衝突修正（優先: 高 / 要承認）

現状: 静穏時間 23:30〜07:00 は催促を送らない一方、6時間無応答で自動一時停止（on_hold）。
23:30 以降に承認カードが出ると、ボスが催促を一度も受け取らないまま停止し得る。
G2 の承認トークン6時間期限も夜間をまたぐと黙って失効する。

**指示（仕様案）:**
1. 無応答カウント（6時間）と G2 トークン期限は、静穏時間の間カウントを凍結する
   （「実働時間で6時間」に統一）。
2. 静穏時間中に発行されたカードの催促は 07:00 にまとめて送る（初回カード即時送信は現行どおり）。
3. `hq` の状態遷移テストに「23:30発行 → 翌朝催促 → 停止しない」ケースを追加する。

## F3. 承認④（担当変更GO）の設計図反映（優先: 中 / 要承認）

ハンドブック v1.2 で追加された承認④が、設計図の関門ラダーとゲート定義に存在しない。

**指示:** 関門ラダーに「作業停滞 → 担当交代提案 → 承認④ → 検証担当の自動反転を再計算」
の分岐を追記。G3（作業者≠検証者）の判定が交代後の担当構成で再評価されることをテストで保証する。

## F4. 正本バックアップの常設（優先: 高 / 承認不要）

正本が Mac ローカルのみに存在し、単一障害点になっている。

**指示:**
1. GitHub にプライベートリポジトリ `aka-ips/hq-backup` を作成する（**必ず private**）。
2. 同梱の `hq_backup.sh` を `~/hq/bin/` に置き、`setup` を1回実行する。
3. launchd または cron で `hq_backup.sh run` を日次実行に登録する。
4. スクリプトの C3 検査（秘密情報スキャン）がヒットした場合はプッシュされない。
   ヒットした場合は該当ファイルを vault へ移すか .gitignore へ追加してから再実行する。

副次効果: ボスは出先からスマホの GitHub アプリで最新の正本・状態ファイルを閲覧できる。

## F5. 投稿フェーズの fail-closed 可視化（優先: 中 / 要承認）

Amazon / SNS は自動検査が未整備のまま「Claude手動チェック」で投稿GOが出せる。

**指示:** 自動検査が未整備のチャンネルへの投稿GOカードには、警告行
「⚠ 自動検査なし・手動確認のみ」を必須表示とする。表示できない場合はカードを発行しない
（不明＝不合格をカード上でも貫く）。

## 適用手順（Mac側Claudeへ）

1. F1・F4 を先に適用（承認不要）。F4 完了時点でバックアップが効き始める。
2. F2・F3・F5 は承認カードを1枚ずつ起票し、ボスの承認語を得てから適用。
3. 各修正の適用後、検証担当（反対側のBOT）による独立再検査を通すこと。
4. 完了したら `hq_backup.sh run` でスナップショットを取り、結果をボスへ4行カードで報告。
